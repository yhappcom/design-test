# LogMate Home Frozen Baseline Contract

This contract is the shared starting point for future visual candidates in this repository.

Preserve:
- Header -> Primary Actions -> Search -> Current Period -> Recent Flights -> Activity -> Totals
- Home remains ad-free
- English-only authored UI
- Current Period = Block Time
- Activity = 7 days / 28 days / 90 days / Custom
- Recent keeps stable Date / Flight / Route / Block comparison
- Flight keeps carrier + number/suffix zoning
- no whole-string Flight centering
- no equal per-character fixed cells
- current comparison Totals = Block / Night / Inst
- existing action/destination semantics remain unchanged

Only visual expression may vary: typography character, color atmosphere, surface/rule language, control/icon treatment, density/spacing finish, brand-accent behavior, and state expression.

Candidate 01 and rejected candidates are not generation inputs.
