# LogMate Visual Continuity Board Brief v0.1

Status: **PORTFOLIO APPROVAL CANDIDATE / NON-LOCKING**
Date: 2026-09-18
Authority: subordinate to master-visual-portfolio-v0.2-detailed-contract.md
Purpose: produce one restrained continuity board for owner review. The board does not lock UI.

## 1. Board question

Does the same LogMate visual language plausibly carry:

Welcome -> Previous Total -> Empty Home -> Add First Flight -> First Populated Home -> Mature Home -> View Logbook

without a fresh visual reinvention at each step?

## 2. Mandatory visual continuity

Use one system throughout:
- warm-neutral or neutral off-white working surface;
- graphite/near-black primary type;
- restrained single accent only for action/focus;
- grayscale-first hierarchy;
- quiet rules before cards;
- low-radius/minimal containment where containment is truly needed;
- precise aligned numerics;
- no lifestyle image;
- no airplane/wing/HUD/runway/cockpit decoration;
- no gradient hero;
- no marketing slogan;
- no generic blue enterprise/dashboard palette;
- no fake premium chrome;
- no bottom navigation invented solely to make the board look complete.

The board should look like a product-design working review, not a pitch deck.

## 3. Working type/density

Use relative hierarchy consistent with current contract:
- LogMate identity: exceptional but restrained;
- page/task title: 20-equivalent;
- section/choice/numeric emphasis: 17-equivalent;
- body/label/action/helper: 15-equivalent;
- never use tiny helper text to create elegance.

Density must visibly progress:
- Welcome: quietest;
- Previous Total: first precision;
- Empty Home: workspace skeleton;
- Add Flight: efficient form;
- First Populated Home: emerging real structure;
- Mature Home: operational summary;
- View Logbook: densest ledger.

## 4. Required seven frames

### 1. Welcome
Must show only:
- LogMate
- Pilot Logbook, if category recognition is needed
- Start a new logbook
- Sign in

No operational sample data.
No ad.
No illustration.

### 2. Previous Total
Show the selected direction in a way that demonstrates:
- Start from zero / Carry forward previous totals as explicit choices;
- a restrained selection row, not giant cards;
- if carry is used for the specimen, show Block/Night/Instrument Flight Time with one H+MM field each;
- full labels;
- value alignment;
- minimal rule geometry;
- no hardcoded claim that these are the final complete eligible field set.

### 3. Empty Home
Show:
- no flights yet;
- Add Flight primary;
- Import secondary;
- Previous Total status;
- actual Home shell beginning to emerge;
- no fake Recent/Activity/Totals;
- no ad.

### 4. Add First Flight
Use current product structure as a compact professional form.
Show:
- Date;
- Flight;
- DEP / ARR;
- Block;
- a few operational fields only as composition evidence;
- Save action;
- no ad;
- no generic stack of oversized rounded fields.

### 5. First Populated Home
Show:
- first real record;
- Add Flight;
- View Logbook;
- only modest emerging summary;
- no ad;
- no celebratory marketing message.

### 6. Mature Home
Show:
- Add Flight / View Logbook access;
- Search;
- Recent;
- Activity;
- Totals;
- a restrained optional reserved banner region at bottom, clearly external to product content;
- avoid KPI-card wall;
- use aligned datum planes and section rules.

### 7. View Logbook
Show:
- landscape phone or bounded landscape ledger specimen;
- dense grid;
- Date / Type / Reg / Flight / DEP / ARR / Block / Night / Inst / Remark;
- Page Total / Previous Total / New Total;
- neutral totals;
- no ad;
- restrained controls;
- same typography/rule language as other frames.

## 5. Board composition

Prefer:
- one large clean neutral canvas;
- seven frames arranged in progression;
- labels outside frames only for frame name / density note;
- no decorative portfolio chrome;
- no dark navy poster background;
- no badges like iOS/PWA/offline-first;
- no explanatory marketing icons;
- no footer slogan.

The board must make screen relationships easy to compare.

## 6. Deliberately provisional

Do not imply final:
- font family;
- exact HEX;
- exact radius;
- exact button height;
- final Home metric semantics;
- final ad implementation;
- final View Logbook column widths.

## 7. Rejection criteria

Reject the board if it:
- looks like a marketing presentation;
- introduces new visual identity;
- uses airplane imagery;
- uses generic blue SaaS UI;
- makes Welcome feel unrelated to View Logbook;
- turns all screens into the same card template;
- invents too many controls to make screens look complete;
- uses tiny text;
- visually treats ads as LogMate content.

## 8. Approval meaning

If approved, the board becomes:
PORTFOLIO-APPROVED continuity reference

It still does not create:
- Welcome Visual Lock;
- Previous Total Visual Lock;
- Home Visual Lock;
- View Logbook Visual Lock.

Those require dedicated screen-family review.
