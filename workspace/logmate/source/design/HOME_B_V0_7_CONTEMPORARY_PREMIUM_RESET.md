# LogMate HOME-B v0.7 — Contemporary Premium Reset

Status: ACTIVE DESIGN CANDIDATE / NOT PRODUCT AUTHORITY
Date: 2026-09-19
Lineage: HOME-B v0.5 -> v0.6 -> v0.7
Trigger: owner review that v0.6 improved but still felt rough and like an older app.

## Problem statement

The remaining dated impression in v0.6 is not primarily a palette problem.

It is produced by a combined visual grammar:
- uppercase micro-labels;
- underlined form/search treatment;
- many thin rules;
- ledger-like metadata columns;
- a large abbreviated month datum;
- text-only Settings;
- rectangular instrument-bar actions;
- dense equal-weight operational readouts.

These choices created precision, but the precision was coded as an industrial/archival interface rather than a current premium native product.

## Current external evidence reviewed

### Apple, 2026
Apple's current design guidance distinguishes simplicity from mere minimalism and emphasizes hierarchy through order, spacing and contrast. Craft is described through high-quality typography, adaptive color, iconography and responsive animation. Current branding guidance says brand expression should be refined and unobtrusive and should defer to content.

Current materials guidance treats modern material/depth primarily as a functional layer for controls and navigation rather than a decoration applied to all content.

Transfer:
- content remains visually open;
- interactive controls may receive a soft material/surface layer;
- brand identity comes from refinement and hierarchy rather than visible branding assets.

### Linear, 2025–2026
Linear's current mobile redesign uses a custom frosted material for navigation/control depth. Its 2026 refresh explicitly reduces competition from secondary interface chrome and emphasizes consistency, scanability and focus. Linear also documents avoiding refraction where it would reduce readability in dense professional interfaces.

Transfer:
- secondary chrome recedes;
- control depth is restrained;
- data remains crisp;
- modernity should not require visual effects on every region.

### Craft, OS26
Craft describes its current OS26 adaptation as lighter, rounder and more fluid, using glass only where it adds clarity and focus.

Transfer:
- introduce contemporary curvature for controls;
- do not turn operational content into rounded cards;
- preserve LogMate density where the task requires it.

## v0.7 design thesis

**Quiet Precision remains the identity intent, but the visual encoding changes from industrial precision to contemporary product precision.**

Internal contrast:

v0.6:
- rules;
- rails;
- abbreviation;
- instrument geometry;
- archival density.

v0.7:
- space;
- hierarchy;
- soft control material;
- natural language casing;
- selective curvature;
- content-first scan rhythm.

## What v0.7 removes

- SEARCH uppercase locator label;
- search underline;
- full-width rule hierarchy as the primary grouping system;
- metadata rail in Recent Flights;
- abbreviated SEP as the primary visual signature;
- text-only Settings;
- rectangular ruled View Logbook action;
- dash-style Activity selection indicator.

## What v0.7 introduces

- small circular Settings control;
- rounded functional action surfaces, without card-dashboard repetition;
- soft search material;
- full natural month name;
- whitespace as the primary section separator;
- date + flight metadata on one quiet line;
- route and duration as the clear flight-row hierarchy;
- compact segmented period control;
- open metric groups without vertical separators;
- separate light/dark surface systems.

## Non-negotiable invariants

- English-only.
- Home ad-free.
- Add Flight primary.
- View Logbook secondary.
- Search immediately after actions.
- current period distinct from rolling Activity.
- Recent Flights / Activity / Totals semantic families preserved.
- 7D / 28D / 90D / Custom preserved.
- no bottom navigation.
- no aviation imagery.
- no marketing copy.
- no fake data change from v0.5 comparison set.
- no stock Card dashboard.
- 200% text and short-height remain hard gates.

## Rejection list

Do not solve modernity with:
- excessive glass;
- gradients;
- glow;
- neon;
- floating cards for every metric;
- giant corner radii everywhere;
- fashionable but illegible display fonts;
- arbitrary icon replacement;
- animated decoration.

## Owner review question

Does v0.7 feel like a current premium professional application while still feeling calm, precise and trustworthy enough for a pilot logbook?

If yes, v0.7 becomes the stronger visual lineage candidate and can then be transferred to Welcome / Previous Total / Empty Home.

If no, reopen the identity model before producing more cosmetic revisions.
