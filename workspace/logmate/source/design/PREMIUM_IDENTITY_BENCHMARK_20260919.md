# LogMate Premium Identity Benchmark — HOME-B v0.6

Status: ACTIVE DESIGN INPUT / NOT PRODUCT AUTHORITY
Date: 2026-09-19
Lineage: HOME-B v0.5 -> v0.6 premium identity pass
Scope: visual character only; product semantics and information architecture remain unchanged.

## Objective

HOME-B v0.5 solved the major structure, semantic, accessibility and reflow problems but still reads as a well-organized system UI rather than an authored premium professional instrument.

v0.6 tests whether premium-brand qualities can be transferred without:
- luxury decoration;
- aviation cosplay;
- imagery;
- metallic textures;
- marketing slogans;
- reduced accessibility;
- product-semantic change.

Working character:
**Quiet Precision**

Secondary test phrase:
**Different but not strange.**

These are internal design descriptors, not product copy.

## Benchmark evidence

### Leica — essential / precision / timeless

Observed brand principles:
- focus on the essential;
- engineering precision and uncompromising quality;
- timeless design;
- clear relationship between function and aesthetics;
- restrained, distinctive form rather than decorative complexity.

Transfer to LogMate:
- make the current period and operational values feel deliberately composed;
- reduce generic icon/chrome vocabulary;
- use precise alignment, numeric rails and controlled contrast as identity carriers;
- prefer one unmistakable detail over many decorative gestures.

Do NOT transfer:
- camera-control mimicry;
- red-dot branding;
- photographic lifestyle imagery;
- literal metal-camera surfaces.

Sources reviewed 2026-09-19:
- Leica — More Than a Camera, a Legacy
- Leica — ZM 1 / ZM 2
- Leica — New Colour Option for Leica Cameras

### Aesop — context / restraint / purposeful material vocabulary

Observed brand principles:
- considered design should improve use;
- utilitarian objects can be beautiful without disguising their utility;
- work with what already exists;
- add merit without imposing a discordant presence;
- local/contextual vocabulary can coexist with a consistent brand foundation.

Transfer to LogMate:
- preserve the validated v0.5 structure instead of replacing it for style;
- treat whitespace and proportion as active design material;
- let professional logbook content provide the atmosphere;
- avoid adding imagery or ornamental surfaces merely to signal premium.

Do NOT transfer:
- retail/interior visual motifs;
- cosmetic-product typography imitation;
- editorial quotations or lifestyle language in the app.

Source reviewed 2026-09-19:
- Aesop — Philosophy on design

### Bang & Olufsen — material honesty / craft / finishing

Observed brand principles:
- rigorous design plus experimentation;
- precision and feeling through craft;
- materials are chosen for beauty, function, longevity and comfort;
- visible material should be honest rather than simulated.

Transfer to LogMate:
- UI “material” must be honest: rules are rules, controls are controls, data is data;
- do not fake aluminium, glass, leather, grain or depth;
- premium quality should appear through exact edge treatment, weight, spacing and state transitions;
- micro-details should reward close inspection.

Do NOT transfer:
- metallic gradients;
- faux anodized texture;
- luxury-product photography;
- decorative skeuomorphism.

Sources reviewed 2026-09-19:
- Bang & Olufsen — Craft Matters
- Bang & Olufsen — Exist to Create
- Bang & Olufsen — Design Stories

### Porsche Design — function / reduction / precision

Observed brand principles:
- maximum functionality;
- reduction to essentials;
- precision and perfection;
- technical detail becomes meaningful when it improves use.

Transfer to LogMate:
- primary/secondary actions should be visually unmistakable without large rounded-card grammar;
- remove generic ornament before adding signature elements;
- precision should be visible in repeated dimensions and alignment.

Do NOT transfer:
- automotive graphics;
- performance/luxury marketing language;
- carbon-fibre or vehicle-instrument styling.

Source reviewed 2026-09-19:
- Porsche Design — Combining functionality and purist design

## Translation matrix

| Dimension | v0.5 condition | v0.6 premium move | Invariant |
| --- | --- | --- | --- |
| Brand carrier | mostly color + generic clean layout | proportion + typography + precision rails + controlled accent | no imagery |
| Header | wordmark + generic settings gear | typographic wordmark + quiet textual Settings control | Settings remains available |
| Actions | rounded filled primary + text secondary | low-radius instrument bar + ruled secondary action | Add Flight primary |
| Search | Material search icon + underline | text-led retrieval line; accent only on focus | Search directly below actions |
| Calendar | centered month between chevrons | asymmetric month datum + subordinate year + compact navigation | same month semantics |
| Recent | two-level rows | metadata rail + route/value axis | same flight data |
| Activity | tab-like text/underline | quieter selector with precise active marker | 7D/28D/90D/Custom |
| Totals | generic rows | reference-ledger rows with stronger numeric alignment | same three candidate slots |
| Color | teal action ownership | graphite/mineral field + sparse petrol accent | semantic state separation |
| Shape | 8px rounded primary | 2px authored control radius; near-square geometry | touch targets preserved |
| Rules | mostly uniform 1px | strong/quiet rule hierarchy | no card panels |
| Type | Roboto role set | same mature fallback, more deliberate role contrast | custom font remains open |
| Motion | generic Ink response | short 120–160ms state movement only | no semantic change |

## v0.6 visual contract

1. No fake luxury material.
2. No gradients used to simulate metal/glass.
3. No rounded-card dashboard.
4. No aviation image or cockpit metaphor.
5. No new Home product feature.
6. No marketing copy.
7. Premium expression must survive grayscale.
8. Premium expression must survive 200% text.
9. Primary task remains visually dominant.
10. Data should look more authored than chrome.
11. Accent is sparse; neutral field carries most of the composition.
12. Signature details must be reusable on Welcome / Previous Total / Empty Home later.

## Acceptance question

v0.6 is successful only if a side-by-side comparison with v0.5 shows:
- same information meaning;
- same task discoverability;
- less generic Flutter/Material character;
- stronger LogMate authorship;
- calmer macro composition;
- finer micro precision;
- no accessibility/reflow regression.

No final visual baseline is implied by this study.
