# LogMate Home Frozen Baseline Contract

Status: **CANONICAL FOR CANDIDATE GENERATION**

Future visual candidates must preserve:
- order: Header → Primary Actions → Search → Current Period → Recent Flights → Activity → Totals;
- Home remains ad-free;
- English-only product-authored UI;
- Current Period represents Block Time;
- Activity periods: 7 days / 28 days / 90 days / Custom;
- Recent operational comparison keeps stable Date / Flight / Route / Block relationships;
- Flight identifier keeps carrier and number/suffix zoning;
- no whole-string Flight centering;
- no equal per-character fixed cells;
- Totals remains Block / Night / Inst for the current comparison fixture;
- action/destination semantics are not changed by visual exploration.

Only visual expression may vary: typography character, color atmosphere, surface/rule language, control/icon treatment, density/spacing finish, brand-accent behavior, and state expression.

Candidate 01 and rejected candidates are excluded as generation inputs.
