## Visual concept
Working name: Independent Signal.

The visual identity is based on signal hierarchy rather than containers. Functional importance is expressed through controlled type contrast, local alignment, selective tonal fields, and short semantic marks. Sections are not turned into a stack of generic cards. Boundaries appear only where they clarify ownership or state.

### Type
- proportional interface voice for labels, actions, navigation, headings, and authored copy;
- mature mono operational role only for confirmed repeated operational identifiers/data;
- tabular figures for proportional summary numerics when available;
- arbitrary user/source text remains fallback-safe proportional text;
- no blanket mono, negative tracking, fixed character cells, or custom unfinished font dependency.

### Color
- neutral-dominant base in both light and dark;
- one restrained brand/accent family may identify primary interactive signal but must not simultaneously carry focus, selection, success, and error meaning;
- consequential states require independent shape/text/boundary cues;
- dark mode is a semantic counterpart, not a cockpit/night-simulation claim.

### Surface / rule language
- whitespace and alignment are primary grouping devices;
- sparse local tonal bands or bounded state regions only where ownership is otherwise ambiguous;
- no card-everything grammar;
- no decorative rails, bezels, aviation motifs, metallic/glass treatment, or rules-everywhere styling.

### Controls / icons
- compact, platform-legible icon primitives with target geometry separated from visible mark size;
- primary actions receive stronger local signal than secondary actions without changing their canonical placement;
- selected/focus/error states remain distinguishable without color alone.

### Density / spacing
- calm Home density without removing canonical information;
- repeated operational rows retain stable local comparison axes;
- spacing creates a deliberate cadence between information families while preserving frozen order and action placement;
- no layout distinctness achieved by moving sections or changing data.

### Brand behavior
- authorship comes from repeated disciplined signal treatment: typographic role separation, selective accent, precise axes, and functional boundaries;
- identity must be transferable beyond Home and therefore cannot depend on a single decorative Home motif.

### State expression
- state is local to the object/region that owns it;
- focus, selected, invalid/ambiguous, recovery and persistence meanings are not collapsed into the brand accent;
- reduced-motion behavior preserves the full semantic result.
